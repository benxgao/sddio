# Routes

## Core

| Type       | Path              | Purpose        |
| ---------- | ----------------- | -------------- |
| SPEC       | `spec/`          | Requirements   |
| ADR        | `adr/`            | Decisions      |
| DISCUSSION | `discussions/`    | Open questions |
| FLOW       | `flow/active/`    | Active work    |
| FLOW       | `flow/completed/` | Completed work |

## Lookup

- SPEC → `spec/`
- ADR → `adr/`
- DISCUSSION → `discussions/`
- ACTIVE FLOW → `flow/active/`
- COMPLETED FLOW → `flow/completed/`

## ID Routing

- `SPEC-*` → `spec/`
- `ADR-*` → `adr/`
- `DISC-*` → `discussions/`
- `FLOW-*` → `flow/`
