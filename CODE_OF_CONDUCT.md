# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be direct about code, be decent to people. Disagreement about a design decision is expected and welcome; harassment, personal attacks and dismissiveness are not.

## Reporting

Report unacceptable behaviour to the maintainer through GitHub. If you need a private channel, a security advisory works and is read by the same person.

Reports are read and acted on. The reporter's identity stays private.

## Enforcement

The maintainer may edit or remove comments, close threads, or block accounts. There is no committee and no appeals process — the project is small, and inventing a bureaucracy would not make it fairer.
