# DISCUSSION

`DISCUSSION` represents unresolved project knowledge.

## Create

Create a discussion when:

* required information is missing
* multiple valid interpretations exist
* user clarification is required
* an unresolved decision affects implementation
* a potential requirement needs confirmation

## Rule

Do not create a discussion for uncertainty that is:

* non-critical
* safely reversible
* irrelevant to future work

## Resolution

When resolved:

1. Record the durable outcome in `SPEC` or `ADR` when appropriate.
2. Resolve the discussion.
3. Avoid duplicating the same information elsewhere.
